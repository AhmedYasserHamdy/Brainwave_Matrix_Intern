# 🛒 Supermarket Sales Analysis

This project is part of my internship at **BrainWave Matrix Solutions**, where I analyzed supermarket sales data to extract business insights using Python.

---

## 📌 Project Description

The objective of this project was to perform an **Exploratory Data Analysis (EDA)** on transactional data from a supermarket, uncovering trends in sales, customer behavior, and product performance.

---

## 🧰 Tools & Libraries Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Key Insights & KPIs

- Total Gross Income per branch
- Top performing product lines
- Customer type vs. total revenue
- Payment method preference
- Sales trends over time
- Gender-wise purchase behavior
- Tax and Rating distribution
